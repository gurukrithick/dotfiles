# Desktop plugins

`themes/` is the local theme carousel (Super+Shift+T). `service.luau` drives
`theme` and the Mango `themes` key mode, `carousel.luau` is the overlay. Needs
plugin API 52 (Noctalia v5.5.0).

`stdout/` is a copy of `tordex/stdout` 1.1.0 (unchanged apart from dropping `examples/`) from
https://github.com/noctalia-dev/community-plugins/tree/29a0756b71f19a38ace074d195be3a14cd6700f6/stdout
(revision `29a0756b71f19a38ace074d195be3a14cd6700f6`). MIT, credits tordex.
To update, replace the directory from a reviewed upstream revision and update
this note.
